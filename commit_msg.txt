docs(rag_best_practices_v2): 0점 케이스 심층 분석 및 프롬프트 개선 결과 추가

What:
- 0점(Zero Score) 평가 케이스에 대한 디버깅을 위한 colab_debug_zero_scores.py 스크립트 작성
- 불량 데이터셋(환각성 함정 문제) 및 LLM의 과도한 보수성(Over-conservatism)에 대한 원인 분석 내용을 src/rag_best_practices_v2/README.md 에 추가
- 프롬프트 유연화 버전인 colab_evaluate_generation_flexible.py 신규 작성 및 평가
- 프롬프트 엔지니어링 후 향상된 품질 최종 평가 점수(Faithfulness: +0.0801, Answer Relevancy: +0.0435)를 두 README 파일에 업데이트

Why:
- 생성(Generation) 평가에서 0점이 나온 원인이 환각 통제와 더불어 "과도한 보수성" 및 데이터의 질적 문제에 있음을 규명하기 위함
- 단순 수치상의 0점을 넘어 시스템의 실질적인 유연성과 통제력을 확인하기 위함
- 프롬프트 힌트 허용 전략이 답변 적합성과 시스템 점수에 직접적으로 기여함을 증명하기 위함

How:
- Python 스크립트를 통해 검색 전후 문서(Context)의 상태와 Reranking 점수를 기록하는 디버깅 파이프라인 구성
- 기존의 하드 룰을 우회하는 '부분적인 힌트' 지시사항을 포함한 새 프롬프트 Python 파일 분리 구성
- 각 README 파일 내 '생성 품질 평가' 섹션 구조화 및 개선 폭 명시
